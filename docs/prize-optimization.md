# Prize Optimization Matrix

## Overall Prize

- Smart contract quality:
  - RBAC + pausable controls + validation guards + custom errors.
  - Expanded contract tests for auth, pause, limits, and rollover.
- Product-market fit:
  - Treasury signer workflow with measurable KPI endpoints (`/kpi`).
- Innovation:
  - Policy-bounded agentic recommendations with deterministic evidence traces.
- Real problem solving:
  - Preventive blocking before fund movement and incident playbook response.

## Best Agentic Project

- Agent output is grounded in explicit rule matches and score thresholds.
- Playbook recommendation is reproducible and testable through `eval:agent`.
- Evaluation report includes accuracy, blocked precision, and blocked recall.

## Grants Positioning

- Milestone plan in `docs/grant-milestones.md` links funding to deliverables and measurable outcomes.
- Launch readiness checklist and submission package establish accountability for milestone-based disbursement.

## Qualification requirement

- Final submission must include Arbitrum-chain deployment addresses and transaction evidence.
