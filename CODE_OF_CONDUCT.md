# Code of Conduct

## Our standard

Arb Guardian is a security-sensitive open-source project. Contributors, maintainers, judges,
operators, and users should communicate with respect, assume good intent, and keep technical
disagreement focused on evidence and outcomes.

We welcome contributions from people of all backgrounds. Harassment, discrimination, threats,
personal attacks, doxxing, sexualized conduct, and deliberate disruption are not acceptable.

## Security-sensitive behavior

Do not publish private keys, credentials, personal data, exploit instructions for an unpatched
deployment, or fabricated deployment evidence. Use the process in [`SECURITY.md`](SECURITY.md) for
vulnerability reports.

## Enforcement

Report a conduct concern privately to the repository maintainers through the contact route described
in [`SECURITY.md`](SECURITY.md). Maintainers may remove comments, reject contributions, or restrict
participation when necessary to protect people or the project.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, reviews, demos,
events, and project-managed communication spaces.
